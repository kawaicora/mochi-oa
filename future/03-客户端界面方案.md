# 客户端界面方案

> 组件：`src/renderer/src/components/`。任务入口在中栏 `TaskSide` + 内容区 `TaskView`（MainScreen `nav==='todo'`）。

## 1. TaskView 顶部：TAPD 式模块导航

在现有「视图切换（列表/看板/甘特图）」上方加一条模块导航（对应 TAPD 顶部栏）：

```
[任务] [需求] [缺陷] [计划] [文档] [Wiki] [仪表盘] [成员跟踪]
```

- 当前选中模块高亮；模块切换后，主区显示对应模块视图。
- 「任务」保留现有列表/看板/甘特图三视图。
- 需求/计划 同样支持 列表/看板/甘特图；缺陷、文档、Wiki、仪表盘、成员跟踪为各自视图。

## 2. 左侧项目侧边栏（TaskSide）

已按 TAPD 卡片化（名称 + 时间范围 + 进度条 + 完成数）。本次增加：点击项目卡片 → 联动右侧模块筛选（`activeProject` 贯穿所有模块列表）。

## 3. 各模块视图组件

| 组件 | 功能 |
|------|------|
| `ReqView.vue` | 需求：列表表格（code/标题/分类/优先级/状态/处理人/预计开始/预计结束）+ 创建/编辑 + 状态流转 + 详情 |
| `BugView.vue` | 缺陷：列表表格（标题/发现版本/严重程度/优先级/状态/处理人/创建人/创建时间）+ 创建/编辑 + 流转 |
| `PlanView.vue` | 计划：列表 + 甘特图（周轴条）+ 创建/编辑 |
| `DocView.vue` | 文档：左侧目录（标题列表）+ 右侧编辑/预览 |
| `WikiView.vue` | Wiki：目录 + 编辑/预览 |
| `DashView.vue` | 仪表盘：统计卡片（近30天新增需求/延期需求/缺陷解决率/未解决缺陷）+ 需求/缺陷分布与趋势图（ECharts 或简单 CSS 条） |
| `MemberTrackView.vue` | 成员任务跟踪：每位成员 完成/进行中/超时 计数 |

## 4. 通用组件

- `AppHeader.vue`（可选）：模块导航栏，供 TaskView 复用。
- `StatusBadge.vue`（可选）：状态/优先级/严重程度彩色徽章。
- 沿用现有 `modal`、`srv-input`、`dt-btn` 样式。

## 5. 数据流

- `stores/app.ts`：新增 `fetchRequirements/fetchBugs/fetchPlans/fetchDocs/fetchWiki/fetchDashboard/fetchMemberTracking` + create/update/status/delete 方法。
- IPC：`shared/ipc.ts`、`preload/index.ts` 暴露 `pantry.req* / bug* / plan* / doc* / wiki* / pm*`；`main/server-ipc.ts` + `main/net/server-client.ts` 转发 socket 事件。
- 事件订阅：`onRequirementsUpdated / onBugsUpdated / ...` 触发刷新（沿用任务系统的 `onTasksUpdated` 模式）。

## 6. 样式基调

浅色办公风（TAPD）：白底、`--dt-border-light` 分隔、主色 `--dt-primary` 高亮，徽章彩色（优先级 Nth=灰/Middle=蓝/High=红；严重度 致命=红/严重=橙/一般=黄/轻微=灰）。表格行 hover 高亮，行点击开详情。
